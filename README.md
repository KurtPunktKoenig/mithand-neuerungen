# Mithand: Neuerungen

Verbesserungen für Mithand-Arbeitsplätze von KI Kurt.

Jede Datei unter `k/` ist für genau einen Arbeitsplatz verschlüsselt. Die Assistenz des Arbeitsplatzes holt sie selbst ab und baut sie ein. Lesbar ist sie nur mit dem Schlüssel dieses Arbeitsplatzes.
